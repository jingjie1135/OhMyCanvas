1. 推荐 API：镜界AI
Base URL：https://mirror.zeabur.app
支持协议：OpenAI / Gemini / 即梦
简介：模型种类齐全，图像、视频、LLM 一站覆盖，支持每日签到送积分，适合想低成本尝鲜各类模型的用户。
API 使用教程：占位

2.我上传了python环境（如果没有会有，就下载python.zip，解压到目录就可以了），现在直接点击运行bat就可以启动了，不需要做更多的设置了

3. 运行成功后，在网页左下角打开 API 设置。使用镜界AI时，请求地址填写 https://mirror.zeabur.app；协议按模型类型选择 OpenAI、Gemini 或即梦，填写 API Key 后即可拉取和选择想要的模型。

4. 想要免费生成就设置modelscope的key，还可以调用lora

5. 想要使用本地comfyui，左下角可以设置comfyui选项，支持导入自定义的工作流
